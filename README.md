## 🌟 Overview

**VexorNull Studio** is an enterprise-grade, browser-based multi-tab code editor and live execution environment designed for developers, designers, and creators. It allows you to write, test, preview, and export complete frontend web applications instantly without installing heavy local IDEs.

Built with modern UI/UX standards, Tailwind CSS, and robust sandboxed execution technology.

---

## ✨ Key Features

- 📑 **Multi-Tab Workspace:** Dedicated editor tabs for `index.html`, `style.css`, and `script.js`.
- ⚡ **Real-Time Live Website Sandbox:** Instant full-stack preview combining HTML, CSS, and JavaScript inside a secure sandboxed iframe.
- 💾 **Automatic Local Storage:** Your work is saved automatically as you type, preventing accidental data loss on page refreshes.
- 📤 **One-Click Export:** Download your entire project as a clean, production-ready `index.html` bundle with a single click.
- 📋 **Universal Code Copy:** Quickly copy your entire multi-file code bundle to your clipboard.
- 📱 **Fully Responsive & Mobile-Optimized:** Designed to work smoothly across desktops, tablets, and smartphones.
